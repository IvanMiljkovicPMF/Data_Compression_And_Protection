# Data_Compression_And_Protection

Repository sadrži dva projekta:

* `Project_1`
* `Project_2`

## Project_1

U direktorijumu `Project_1` nalaze se 3 zadatka:

* `Assignment_1`
* `Assignment_2`
* `Assignment_3`

U svakom `Assignment` direktorijumu nalaze se fajlovi:

* `Izvestaj_Zadatak_<broj>` – izveštaj za dati zadatak
* `Izvori_Zadatak_<broj>` – izvori korišćeni za izradu zadatka
* `Uputstvo_Za_Pokretanje_Zadatak_<broj>` – uputstvo za pokretanje programa

### Struktura Project_1

```text
Project_1/
├── Assignment_1/
│   ├── Izvestaj_Zadatak_1
│   ├── Izvori_Zadatak_1
│   └── Uputstvo_Za_Pokretanje_Zadatak_1
│
├── Assignment_2/
│   ├── Izvestaj_Zadatak_2
│   ├── Izvori_Zadatak_2
│   └── Uputstvo_Za_Pokretanje_Zadatak_2
│
└── Assignment_3/
    ├── Izvestaj_Zadatak_3
    ├── Izvori_Zadatak_3
    └── Uputstvo_Za_Pokretanje_Zadatak_3
```
