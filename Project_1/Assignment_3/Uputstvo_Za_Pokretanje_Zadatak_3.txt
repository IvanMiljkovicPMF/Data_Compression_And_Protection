UPUTSTVO ZA POKRETANJE – ZADATAK 3

1. Otvoriti fajl Project_1.sln u programu Microsoft Visual Studio.

2. U Visual Studio-u izabrati:
   Build pa onda Build Solution

   Time se projekat prevodi i priprema za pokretanje.

3. U Solution Explorer-u pronaći projekat Assignment_3.

4. Kliknuti desnim klikom na projekat Assignment_3.

5. Izabrati:
   Debug pa onda Start Without Debugging

6. Program će se pokrenuti u konzolnom prozoru.

7. Program očekuje ulazni fajl:
   apache_loghub.log

   Fajl apache_loghub.log nalazi se u okviru projekta
Assignment_3, tako da program može direktno da ga učita prilikom pokretanja.

8. Nakon pokretanja program prvo obrađuje LZ77, a zatim LZW.

9. Na kraju se u konzoli prikazuju rezultati dekodiranja, veličina komprimovanog fajla, compression ratio i space saving za oba algoritma.
